\# Vagrant-стенд c PAM



\## Текст задания

1\. Развернуть виртуальную машину с помощью Vagrant.

vagrant up

vagrant ssh

2\. Настроить PAM-модуль (`pam\_exec`) для логирования/проверки входа.

3\. Настроить пользователя `otusadm`, добавить его в группу `docker`, чтобы команды выполнялись без `sudo`.

4\. Настроить беспарольный перезапуск службы Docker через `sudoers`.
